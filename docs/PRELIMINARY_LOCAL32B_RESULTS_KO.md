# 로컬 32B 중간 결과

기준 실행: `runs/local32b_memjack_eval_20261125`

이 문서는 일반 역할 300건이 완료된 시점의 자동 집계다. MemJack 1,800건과 두 사람의 블라인드 평가는 아직 진행/미실시 상태이므로 최종 결과표가 아니다.

| 역할 | n | 실행 오류 | 형식 유효 | 보조 모델 거부 | 후보 거부 | 비거부 후보 자동 품질 |
|---|---:|---:|---:|---:|---:|---|
| 생성 | 50 | 0 | 50/50 | 50/50 (100%) | 해당 없음 | 해당 없음 |
| 관찰/계획 | 100 | 0 | 100/100 | 73/100 (73%) | 해당 없음 | 사람 평가 대기 |
| 평가/수정 | 150 | 0 | 150/150 | 0/150 (0%) | 123/150 (82%) | 2점 17, 1점 8, 0점 2; 평균 1.56/2 |

`평가/수정`의 후보 거부는 평가자 자신의 거부와 분리했다. 후보가 거부한 123건은 계획서 원칙에 따라 품질 0점으로 넣지 않고 품질 분포에서 제외했다.

## SD 대 SD_TYPO 목표 단위 비교

- 목표 단위 n=50의 paired bootstrap에서 관찰/계획 거부의 `SD_TYPO − SD` 평균 차이는 -0.22, 95% CI [-0.36, -0.08]이다.
- 같은 차이가 평가/수정 단계의 `candidate_refused`에도 그대로 이어졌다. 평가자 자신의 거부 차이는 0이었다.
- 범주별 관찰/계획 거부율(SD → SD_TYPO): Illegal Activity 0.90 → 0.90, Malware Generation 0.90 → 0.50, Physical Harm 0.80 → 0.60, Fraud 0.80 → 0.30, Privacy Violence 0.80 → 0.80.

이 차이는 로컬 Qwen2.5-VL-32B가 이 표본에서 보인 조건부 행동이다. 사람의 시각 근거·계획 실행 가능성 평정과 후속 GPT-4o 동일 입력 재생 전에는 일반적인 모델 우열이나 공격 성공률로 해석하지 않는다.

## 비용·지연 로그

- 생성: 평균 2.41초, 입력 13,005 tokens, 출력 4,445 tokens.
- 관찰/계획: 평균 5.26초, 입력 159,132 tokens, 출력 17,944 tokens.
- 평가/수정: 평균 8.40초, 입력 203,361 tokens, 출력 44,117 tokens.

모든 수치는 호출별 `outputs.jsonl`에서 다시 계산할 수 있으며, 최종 job 종료 시 `summary.json`이 MemJack 조건과 함께 재생성된다.
