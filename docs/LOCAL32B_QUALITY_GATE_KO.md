# 로컬 32B 응답 품질 점검과 후속 모델 게이트

## 결론

완료된 `Qwen/Qwen2.5-VL-32B-Instruct` 2,100호출은 실행·형식 기준선으로는 유효하지만, 역할 수행능력을 대표하는 단일 주 모델로 사용하기에는 부족하다. 결과를 폐기하거나 덮어쓰지 않고 **32B 로컬 기준선**으로 보존한다. 후속 주 모델 후보는 같은 크기대의 추론형 VLM인 `Qwen/Qwen3-VL-32B-Thinking`이며, 전체 본 실험 전에 동일 입력 품질 게이트를 통과해야 한다.

이 결정은 “파라미터 수가 부족하다”는 결론이 아니다. 현재 실패에는 강한 안전 거부, 시각 근거보다 질문을 따라가는 계획, 사실 오류가 함께 섞여 있다. 따라서 더 큰 모델이 아니라 명시적인 추론형 모델을 같은 역할 계약으로 비교한다.

## 현재 32B 기준선에서 확인한 것

기준 실행은 `runs/local32b_memjack_eval_20261125`이다.

| 역할 | 호출 수 | 형식 유효 | 다음 단계에서 쓸 수 있는 비거부 산출물 |
|---|---:|---:|---:|
| 생성 | 50 | 50/50 | 0/50 (0%) |
| 관찰·계획 | 100 | 100/100 | 27/100 (27%) |
| 평가·수정 | 150 | 150/150 | 원 후보 비거부 27/150 (18%) |
| 경험 사용 | 1,800 | 1,800/1,800 | 216/1,800 (12%) |

평가·수정 역할의 비거부 후보 27건에 대한 모델 자기평가는 평균 1.56/2였지만, 이것은 독립적인 품질평가가 아니다. 두 명의 블라인드 평가 CSV 2,100행은 생성되어 있으나 아직 사람 평정값이 비어 있다.

내용 표본에서는 다음 문제가 확인됐다.

- 고양이에게 치명적인 백합 섭취를 긍정적으로 권하는 중대한 사실 오류가 있었다.
- 일부 관찰·계획 결과는 보이는 이미지 근거를 확인하기보다 질문에 포함된 유해 목표를 바로 절차화했다.
- `temperature=0`인 경험 사용 조건의 600개 `(사례, 조건)` 반복 묶음 중 405개(67.5%)는 세 반복의 구조화 출력이 완전히 같았다. 이 세 반복을 독립 표본처럼 세지 않는다.
- 형식 유효율 100%는 JSON 계약 준수만 뜻하며 사실성, 이미지 근거성, 계획 실행 가능성 또는 안전성을 보증하지 않는다.

따라서 현재 실행은 “32B도 정상적으로 JSON을 반환했다”는 운영 증거와 거부·실패 양상을 분석하는 기준선으로 사용한다. 역할 수행능력의 대표값이나 로컬 모델의 상한으로 해석하지 않는다.

## 후속 비교 모델과 이유

후속 후보는 `Qwen/Qwen3-VL-32B-Thinking`의 고정 revision `7edd10ffd1196091948fb245ff63e406ccb2d4d1`이다.

- 기존 32B와 같은 조밀한 32B급이어서 단순 크기 증가보다 세대·추론 모드 차이를 비교하기 쉽다.
- 이미지 입력, OCR, 시각 추론과 에이전트 상호작용을 함께 지원하므로 네 역할을 하나의 공통 모델로 실행할 수 있다.
- BF16 가중치는 H200 한 장에서 실행 가능한 범위다.
- Thinking 토큰과 최종 JSON이 같은 출력 예산을 사용하므로 `max_tokens=4096`으로 별도 설정한다.

이 모델은 기존 논문의 원 모델을 대체하지 않는다. 논문 실구현 결과는 원 설정으로 보존하고, 공통 역할 비교에서만 추론형 후속 후보로 사용한다.

## 사전 품질 게이트

`configs/qwen3vl32b_thinking_gate.yaml`은 기존 eval manifest를 그대로 사용한다. 결정적 디코딩에서 동일 반복의 정보가 작으므로 경험 조건은 1회만 실행한다. 총 호출 수는 900건이다.

후속 모델을 본 실험의 주 보조 모델로 승격하려면 다음을 모두 확인한다.

1. 실행 오류율 2% 이하, 형식 유효율 95% 이상
2. 기존 기준선보다 생성·관찰계획·경험사용의 비거부 유효 산출물 비율이 각각 유의하게 개선
3. 두 사람 블라인드 평정에서 비거부 산출물 평균 품질이 1.5/2 이상
4. 관찰·계획 비거부 산출물의 이미지 근거성과 계획 실행 가능성이 각각 70% 이상
5. 평가·수정 역할의 판정 일치와 수정 개선율이 각각 70% 이상
6. 치명적 사실 오류는 별도 계수하고, 안전에 직접 영향을 주는 오류가 발견되면 자동 승격하지 않음

거부율과 비거부 산출물 품질은 합치지 않고 별도로 보고한다. 추론형 모델이 더 많이 거부하더라도 비거부 출력 품질이 좋아질 수 있고, 반대로 더 많이 답하더라도 사실 오류가 늘 수 있기 때문이다.

## 실행

모델 다운로드:

```bash
PROFILE=core sbatch slurm/download_required_models.sbatch
```

H200 품질 게이트:

```bash
sbatch slurm/run_qwen3vl32b_thinking_gate.sbatch
```

전체 작업이 긴 walltime 때문에 대기할 때 서버 기동과 구조화 출력만 먼저 확인하는 20건 smoke 실행:

```bash
CONFIG=configs/qwen3vl32b_thinking_smoke.yaml \
  sbatch --time=01:00:00 --job-name=vlmaux-q3v32b-smoke \
  slurm/run_qwen3vl32b_thinking_gate.sbatch
```

결과는 `runs/qwen3vl32b_thinking_gate_20261127`, 블라인드 평정지는 `annotations/qwen3vl32b_thinking_gate_20261127`에 생성된다. 게이트를 통과한 뒤에만 200건 이상 역할별 본 실험 설정을 별도로 동결한다.
