# 공개 구현 및 논문 설정 대응표

이 프로젝트의 1차 목표는 원 논문의 ASR을 재현하는 것이 아니라, 동일한 역할 입력을 보조 모델에 재생해 실제 모델 호출 단위로 거부·품질·비용을 비교하는 것이다. 따라서 아래에서 원형 보존과 통제 실험용 변형을 분리한다.

| 기법 | 원형에서 보존하는 부분 | 이번 역할 비교의 변형 | 원형 재현에 추가로 필요한 것 |
|---|---|---|---|
| FigStep | 작성 산출물과 고정 타이포그래피 렌더러 결과를 분리 | HarmBench Standard 목표를 사용 | SafeBench 전체 조건을 재현할 때 공식 질문 사용 |
| HADES | 이미지 캡션 → 1–10점 평가와 설명 → 다음 이미지 프롬프트의 반복 정보 흐름, 최대 5회 | 32B VLM이 역할별 별도 호출을 담당할 수 있음 | PixArt 체크포인트와 고정 caption/judge 모델 |
| HIMRD | 실패 후보 목록을 다음 prefix/suffix 재작성에 제공, 이해와 순응을 분리 | 고정 JSON 출력 규격 추가 | 실제 표적 응답 및 원 구현의 표적 모델 체크포인트 |
| MM-Plan | 이미지 근거, 계획, 허용 동작을 분리 기록 | MM-SafetyBench 이미지에서 inference-only 32B 비교 | VE-Safety DUA, Qwen3-VL-4B 기반 GRPO 체크포인트 또는 8-GPU 재학습 |
| MemJack | train split 경험만 사용, 피드백/메모리/무작위 메모리 조건 분리 | 공개 궤적을 공통 경험 은행으로 고정하고 모델 호출 전에 목표별 검색·길이 매칭 무작위 대조군을 manifest로 확정 | 표적 모델을 포함한 전체 멀티턴 공격 실행 |

근거:

- 실험 계획서 PDF p. 1: HarmBench 20/50, MM-SafetyBench 20/50 및 SD/SD_TYPO 목표 단위 짝짓기.
- 실험 계획서 PDF p. 2: 네 역할의 공개 코드 연결과 FigStep 렌더러, HADES 캡션 평가, MM-Plan 허용 동작 분리.
- 실험 계획서 PDF p. 3: 거부를 품질 0점과 분리하고, 0/1/2점·오류·미도달을 별도 집계.
- 실험 계획서 PDF p. 4: MemJack A/B/C, 3회 반복, 목표별 질의 상한 3, 개발 경험 은행 고정, 무작위 경험 대조.
- 실험 계획서 PDF p. 5: 파일 경로·원본 ID·실제 입력·중간 산출물·다음 소비자까지 기록하고 파일럿 후 전체 실행.
- 진행 중 서베이 PDF p. 13, Table 5: FigStep, MM-SafetyBench, HADES의 입력·출력·다음 사용과 프로그램 실행 경로.
- 진행 중 서베이 PDF pp. 13–14, Tables 6–7: 역할 조합과 기법 내 통제 실험을 서로 다른 ASR의 단순 비교와 구분.
- 진행 중 서베이 PDF p. 16, Table 8: HarmBench와 MM-SafetyBench의 자원 및 조건을 구분.

공개 코드 커밋과 데이터 SHA-256은 각 실행의 `provenance.json`과 데이터 summary에 고정된다.
